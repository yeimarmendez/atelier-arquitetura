# Atelier Arquitetura

Projeto web desenvolvido com React, TypeScript, TanStack Start e Vite.

## Executar localmente

Requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

> Observação: este projeto usa TanStack Start (com servidor). Publicar o código no GitHub não publica automaticamente o site; GitHub Pages não hospeda diretamente a aplicação com SSR. Para publicar a aplicação, use uma plataforma compatível com o servidor/adaptador de build.
